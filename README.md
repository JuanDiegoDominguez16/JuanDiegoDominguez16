##  About Me

Hey! I'm **Juan Diego**, a Systems Engineering student at [Universidad Icesi](https://www.icesi.edu.co/), based in Cali, Colombia 🇨🇴.

I'm passionate about understanding how software works, solving challenging problems, and building digital experiences that are both functional and intuitive.

- 🎓 Studying **Systems Engineering** at Universidad Icesi.
- 💻 Exploring **Frontend Development** and modern web technologies.
- 🎨 Interested in **UX/UI Design**, visual design, and user-centered interfaces.
- 🧩 Learning through hands-on projects in software engineering and computer science.
- 🌱 Continuously improving my programming, problem-solving, and design skills.
- 🚀 Working toward becoming a versatile software developer who understands both code and the people who use it.

> *Good software isn't just about making things work. It's about making them work well for people.*
